# Release Acceptance Checklist

- User can register, log in, view profile, and log out.
- User can create courses and upload supported materials.
- Worker parses materials, creates chunks, embeddings, and marks materials READY.
- User can ask course questions and see answer citations.
- User can generate study plans, preview generated tasks, and create todos.
- User can generate course summaries from READY chunks.
- User can run multi-course planning analysis and create a unified study plan.
- Dashboard shows courses, READY ratio, today tasks, recent chats, and plans.
- Admin can open status, dependency, failed material, and queue views.
- `python -m pytest`, `npm run build`, and `npm run test:e2e` pass.
